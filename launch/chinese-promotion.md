# Chinese-language promotion

Tracking issue: [#102](https://github.com/Allra-Fintech/texio/issues/102).

## Positioning

**Name:** Texio

**Category:** 开源项目 / AI 编程开发工具

**Short description:** 让 AI 安全编辑指定 Markdown 章节

**Full description:**

> Texio 是面向 shell 脚本和编码 Agent 的免费 MIT 开源 Markdown
> 命令行工具。它按标题结构查找、读取和替换指定章节，支持 dry-run
> 差异预览；当标题缺失或重复时会拒绝写入，避免正则表达式或整文件重写
> 越过章节边界。提供 crates.io、macOS/Linux/Windows 二进制、Homebrew
> 和 Agent Skill。项目目前以英文文档为主，GitHub 在中国大陆的可访问性
> 取决于网络环境。

Project URL: https://github.com/Allra-Fintech/texio

The copy describes Texio as deterministic tooling for coding agents. It does
not claim that Texio is a generative model or that GitHub is directly reachable
from every network in mainland China.
